# Extra Scope

Сервис для глубокого анализа Telegram-каналов и оценки ключевых метрик эффективности.

## Источники (без токенов)

- Telegram: публичная веб-лента `https://t.me/s/<channel>`
- MAX:
  - публичный каталог `https://maxchart.ru/channel/<channel>`
  - прямой fallback `https://max.ru/<channel>`

Все данные берутся только из открытых страниц, без API-ключей и без платных интеграций.

## Переменные окружения (опционально)

```bash
export API_TIMEOUT_MS=12000
# при необходимости можно переопределить базовые URL:
export TELEGRAM_PUBLIC_BASE_URL=https://t.me/s
export MAXCHART_BASE_URL=https://maxchart.ru
export MAX_PUBLIC_BASE_URL=https://max.ru
# настройки нестрогого матчинга:
export MAX_MATCH_THRESHOLD=0.5
export MAXCHART_SEARCH_PAGES=8
export MAXCHART_SEARCH_PAGE_SIZE=20
```

## Запуск

```bash
npm start
```

После запуска откройте:

`http://127.0.0.1:3000`

## Что делает

- принимает `@username` или `https://t.me/username`;
- парсит открытые метрики Telegram (подписчики, средние просмотры, частота постов по ленте);
- проверяет наличие одноименного канала в MAX сначала по каталогу, затем напрямую по `max.ru`;
- если точного username нет, ищет похожий канал по имени/username в каталоге MAX;
- показывает доступные метрики MAX (подписчики, изменение за 24 часа, частота постов);
- строит сравнение платформ и графики только по доступным открытым данным.

## Ограничения открытых данных

- часть метрик может быть недоступна (например, ER/охваты/комментарии по MAX);
- сравнение выполняется по тем полям, которые реально присутствуют на публичных страницах;
- проверка MAX делается сначала по точному username, затем по похожим названиям;
- при нестрогом сопоставлении используется `confidence` (по умолчанию порог 50%).

## Формула среднего охвата поста

`Средний охват поста (%) = (Сумма просмотров (или взаимодействий) по выборке постов / Количество постов / Количество подписчиков) × 100%`
