FAQ

Как работает сервис?

Вы вводите Telegram-канал, сервис забирает открытые данные из публичной ленты Telegram (`t.me/s`), затем ищет соответствующий канал в MAX через `maxchart.ru` и fallback на `max.ru`, после чего строит сравнение.

Какие источники данных используются?

Только открытые веб-источники без токенов: Telegram web preview (`t.me/s`) и MAX страницы (`maxchart.ru`, `max.ru`).

Как считается средний охват поста (%)?

Формула: (Сумма просмотров или взаимодействий по постам / Количество постов / Количество подписчиков) × 100%.

Как сервис понимает, что канал в MAX тот же самый?

Сначала используется точное совпадение username. Если его нет, включается нестрогое сопоставление по похожести названия/username с `confidence`. По умолчанию порог совпадения — 50%.

Почему часть метрик может быть недоступна?

Не все площадки отдают одинаковый набор публичных данных. Если метрика недоступна в открытом источнике, в интерфейсе показывается `н/д`.
